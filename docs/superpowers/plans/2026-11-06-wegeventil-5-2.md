## Review Focus

1. **Beide Signale gleichzeitig (bistabil):** 14 und 12 zugleich gedrückt → der Schieber bleibt, wo er ist, und pendelt nicht. → Test in Task 2.
2. **Niedrigster Druck (2 bar):** das monostabile Ventil schaltet trotzdem (Steuerkraft > Feder + Haftreibung), nur langsamer als bei 6 bar. → Test in Task 2.
3. **Bauart wechseln mitten im Umschalten:** Schalter mono/bi während der Zeitlupe → das Modell geht in die Ausgangsstellung 12, Signale aus, kein Schieber bleibt in der Mitte hängen. → Test in Task 2 (Modell) und Task 8 (Browser).

5. **Signal halten und dann wegziehen:** Maus verlässt den gedrückten Knopf 14, Finger wird abgebrochen, oder „Zerlegen" während des Haltens → das Signal endet (monostabil fällt zurück), Automatik stoppt beim Zerlegen. → Test in Task 8.

**Interfaces:**
- Consumes: `AUSSEN`, `wegeOffen`, `kammerSchritt`, `ventilBegrenze` (Task 1)
- Produces:
  - `export const ISO_5599_GR1` – Objekt mit genau diesen Schlüsseln und Startwerten (Annahmen außer wo vermerkt):
    `hub: 7, bohrung: 13, steuerkolben: 20, masseSchieber: 0.03, federVor: 30, federRate: 1.5, haftreibung: 8, gleitreibung: 5, viskos: 2, leitwertSteuer: 8e4, volumenSteuer: 5000, leitwertZu: 3.2e5, leitwertAb: 3.2e5, volumen2: 59000, volumen4: 59000, ueberdeckung: 0.3`

  - `export function neuesVentil(masse, { bauart = "monostabil", druckBar = 6 } = {})` → Zustand `{ bauart, anteil: 0, geschw: 0, p12: AUSSEN, p14: AUSSEN, p2: AUSSEN + druckBar, p4: AUSSEN, signal12: false, signal14: false, hand: null, schaltStart: null, schaltzeit: null }` (Ausgangsstellung 12: 1→2 offen, 4 entlüftet)
  - `export function ventilSchritt(v, masse, dt, druckBar)` – mutiert und gibt `v` zurück; feste Teilschritte 1/20 000 s, `dt` gedeckelt auf 0,1 s
  - `export function ventilSignal(v, name: "12" | "14", an: boolean)` – setzt das Signal, beendet `hand`; `"12"` bei `bauart === "monostabil"` wird ignoriert
  - Alle Top-Level-Namen in `ventil.mjs` beginnen mit `ventil`/`Ventil` oder sind `AUSSEN`, `ISO_5599_GR1`, `wegeOffen`, `kammerSchritt`, `neuesVentil`, `bauartWechseln`, `vonHand` – damit sie neben `pneumatik.mjs` und den Laufzeiten eingebettet werden können
  - `export function bauartWechseln(v, masse, bauart, druckBar)` – setzt `v` auf `neuesVentil(masse, { bauart, druckBar })` zurück (Werte in-place)
  - `export function vonHand(v, anteil: number)` – `hand = anteil` (0…1 begrenzt), `anteil = hand`, `geschw = 0`, Signale bleiben unverändert
  - `export function ventilSchaltzeit(masse, druckBar, { bauart = "monostabil", richtung = "14" } = {}): number` – Sekunden vom Signal bis `anteil` ≥ 0,98 (bzw. ≤ 0,02), simuliert mit `ventilSchritt` auf einer Kopie; `Infinity`, wenn nach 1 s nicht erreicht
  - `export function ventilAnzeige(v, masse, druckBar): { p2: number, p4: number, schaltzeitMs: number }` – `p2`, `p4` Überdruck in bar auf 0,1 gerundet; `schaltzeitMs` = gemessene letzte Schaltzeit, sonst `ventilSchaltzeit(masse, druckBar)` · 1000, gerundet

Physik je Teilschritt (Reihenfolge verbindlich, weil die Tests darauf beruhen):
1. Steuerkammern: Quelle für 14 ist `AUSSEN + druckBar`, wenn `signal14`, sonst `AUSSEN` (entlüftet über das Signalventil); `q = leitwertSteuer · (quelle − p)`; `p14 = kammerSchritt(p14, q, 0, volumenSteuer, h, max(quelle, p14))`; ebenso `p12`.
2. Kräfte auf den Schieber in N, positiv Richtung Stellung 14: `0.1·(p14 − AUSSEN)·A_st − 0.1·(p12 − AUSSEN)·A_st` mit `A_st = π·steuerkolben²/4`; monostabil zusätzlich Feder `−(federVor + federRate·anteil·hub)`; bistabil keine Feder.
3. Reibung wie beim Kolben: steht der Schieber (`|geschw| < 1 mm/s`) und `|F| ≤ haftreibung` → bleibt stehen; sonst `F − sign·gleitreibung − viskos·geschw/1000`.
4. Bewegung: `geschw += h·F·1000/masseSchieber` (mm/s), `anteil += h·geschw/hub`, Anschläge bei 0 und 1 ohne Rückprall.
5. Bei `hand !== null`: Schritte 2–4 entfallen, `anteil = hand`.
6. Arbeitskammern: `o = wegeOffen(anteil, ueberdeckung)`; `q4 = o.a·leitwertZu·(quelle − p4) + o.b·leitwertAb·(AUSSEN − p4)`; `q2 = o.b·leitwertZu·(quelle − p2) + o.a·leitwertAb·(AUSSEN − p2)`; `p2/p4 = kammerSchritt(…, 0, volumen2/4, h, quelle)`.
7. Schaltzeit messen: ein Signalwechsel setzt `schaltStart`; erreicht `anteil` die Zielendlage, wird `schaltzeit` gesetzt und `schaltStart = null`.
